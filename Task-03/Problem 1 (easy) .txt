Question Link: https://leetcode.com/problems/remove-element/description/
Problem: 27. Remove Element
Difficulty: Easy

Approach:
We need to find the total number of elements that are not equal to val
and also make sure the nums list stores those values at the front.
I defined a variable k starting at 0 to track the position.
Iterating through the list, whenever an element is not equal to val,
we place that element at index k (nums[k] = i) and increase k by 1.
Finally, returning k gives the number of valid elements.

My Code:
class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        k = 0
        for i in nums:
            if i != val:
                nums[k] = i
                k += 1
        return k
