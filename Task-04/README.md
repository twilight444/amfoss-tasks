## Approach

* **Web Structure**: Created a two-page layout using HTML and CSS for a main coin list and a coin details page.
* **AI Assistance**: I've used AI to write and simplify the JavaScript code for fetching data, filtering, and updating the UI.(Only Javascript)
* **Live Market Data**: Connected the app to the CoinGecko API to fetch the top 25 cryptocurrencies and auto-refresh the prices every 30 seconds.
* **Search & Wishlist**: Added a live search bar and a wishlist filter so users can find specific coins and toggle their favorites.
* **Details & Price Charts**: Used the coin ID in the link to load coin details and displayed price history graphs across different timeframes using Chart.js.
* **Saving Preferences**: Used browser storage to save favorite coins so the wishlist stays saved when switching pages or refreshing.
